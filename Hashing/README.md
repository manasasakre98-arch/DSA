# Hashing in C++

This folder contains important Hashing problems and concepts
practiced in C++ for coding interviews and placements.

## Problems Covered

1. Frequency of Elements
2. First Non-Repeating Element
3. First Repeating Element
4. Remove Duplicates
5. Subarray Sum Equals K
6. Longest Subarray With Sum K

## Concepts

- unordered_map
- unordered_set
- Frequency Counting
- Prefix Sum + HashMap
- Subarray Sum Problems

## Complexity

Most hashing solutions achieve:

- Time Complexity: O(n) average
- Space Complexity: O(n)
